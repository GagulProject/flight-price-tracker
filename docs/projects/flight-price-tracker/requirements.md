# 항공권 가격 추적

서울↔도쿄 왕복 일정의 가격을 네이버 항공권과 트립닷컴에서 주기적으로 확인해 GitHub Pages에 보여줍니다.

## 요구사항

- R1. 2026-12-30 출발, 2027-01-01 귀국, 성인 1명, 일반석의 왕복 가격을 사이트별로 표시한다.
- R2. 확인된 사이트별 금액 중 최저가와 가격 확인 시각, 마지막 조회 시각을 구분해 보여준다.
- R3. 사이트 카드를 누르면 해당 항공권 사이트의 검색 페이지로 이동한다.
- R4. 6시간마다 가격 확인을 시도하며, 조회 실패 가격을 최신 금액으로 표시하지 않는다.
- R5. 작은 화면에서도 가격과 여정 조건을 읽을 수 있다.

## 완료 기준

- 가격 데이터 형식 검사와 정적 페이지 배포가 성공한다.
- 가격을 표시한 출처의 날짜·왕복·인원·통화 조건이 일치한다.
- 정기 조회가 실제로 예약되고 한 번 실행되어 저장 결과가 검증된다.
