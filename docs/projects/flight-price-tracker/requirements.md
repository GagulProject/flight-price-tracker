# 항공권 가격 추적

사용자가 원하는 왕복 여정을 입력해 추적 중인 가격을 조회하고, 새 여정을 추적 목록에 추가할 수 있습니다.

## 요구사항

- R1. 출발 도시·도착 도시·출발일·귀국일로 추적 중인 왕복 일정을 조회한다.
- R2. 조회된 일정마다 네이버 항공권·트립닷컴·Google 항공편·스카이스캐너의 확인된 가격, 사이트별 검색 링크, 최근 조회 시각을 보여준다.
- R3. 일치하는 일정이 없으면 입력값이 채워진 GitHub Issue에서 추적을 요청할 수 있다. Issue 제출이 필요하다는 사실을 페이지에 표시한다.
- R4. 6시간마다 새 요청을 확인해 유효한 일정을 등록하고, 등록된 모든 일정의 가격 확인을 시도한다.
- R5. 조회 실패 가격을 최신 금액처럼 표시하지 않는다. 작은 화면에서도 입력과 결과를 읽을 수 있다.
- R6. 사용자가 게시된 가격 데이터를 버튼으로 다시 불러올 수 있다. 버튼이 항공권 사이트의 즉시 재조회를 뜻하지 않도록 표시한다.
- R7. 사이트별로 확인된 가격 이력을 누적하고 시간에 따른 가격 변화를 여정 카드에 보여준다. 기록이 하나뿐이면 실제 변화가 확인된 것처럼 선을 그리지 않는다.

## 완료 기준

- 입력한 기존 일정과 미등록 일정의 화면을 각각 확인한다.
- 가격 데이터의 전체 일정에 대한 형식 검사와 정적 페이지 게시를 확인한다.
- 새 Issue가 실제 예약 실행에서 등록되고 가격 데이터가 게시되는지 확인한다.
