# 구현 계획

## 구조

```mermaid
flowchart LR
  A[네이버 항공권·트립닷컴 검색] --> B[Codex 6시간 조회]
  B --> C[data/prices.json]
  C --> D[GitHub Pages 배포]
  D --> E[사이트별 가격 카드]
```

각 출처의 실제 검색 결과에 왕복 일정과 가격이 함께 보이는 경우에만 금액을 기록합니다. 가격을 읽지 못하면 해당 출처는 확인 대기로 표시합니다. 페이지는 정적 파일을 읽어 카드와 최저가를 계산합니다.

## 검증

`npm run check`로 날짜·사이트 링크·가격 상태를 확인합니다. GitHub Actions 배포 결과와 공개 URL에서 렌더링을 확인합니다. 예약된 Codex 작업을 한 번 실행해 데이터 갱신과 게시 시각을 확인합니다.
