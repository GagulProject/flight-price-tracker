# Flight Watch

GitHub Pages에서 왕복 항공권 가격 추적 일정을 조회하는 사이트입니다. [공개 페이지](https://gagulproject.github.io/flight-price-tracker/)에서 출발 도시·도착 도시·가는 날·오는 날을 입력하면 등록된 일정의 네이버 항공권·트립닷컴·Google 항공편·스카이스캐너 가격과 최근 조회 시각을 볼 수 있습니다.

조회 결과가 없으면 **이 일정 추적 요청하기**를 눌러 입력값이 채워진 GitHub Issue를 제출할 수 있습니다. GitHub 로그인이 필요합니다. Issue를 자동 등록하는 작업은 아직 연결되지 않았으므로, 요청 후 추적 목록 반영은 별도로 확인해야 합니다. 페이지의 입력만으로 새 일정이 저장되지는 않습니다. 추적 범위는 왕복·성인 1명·일반석입니다.

**게시 데이터 새로고침**은 현재 공개된 가격 JSON을 다시 불러옵니다. 항공권 사이트에 즉시 새 가격 조회를 요청하지는 않습니다.

## 데이터 갱신

`data/prices.json`의 `routes`에 여정별 가격을 저장합니다. 각 가격은 해당 날짜·여정의 실제 검색 결과에서 확인한 값만 기록합니다. 조회 실패 시 `status: "unavailable"`, `priceKrw: null`, `checkedAt: null`로 기록하고 `lastAttemptAt`은 마지막 조회 시각으로 갱신합니다. 출처별 검색 URL에는 같은 여정 조건이 들어가야 합니다. `npm run check`가 모든 일정의 형식·날짜·가격·링크를 검증합니다.

각 사이트의 `history`에는 실제 확인한 가격과 시각을 오래된 순서부터 저장합니다. 같은 가격이 다시 확인되어도 새 시각의 기록을 추가하며, 조회에 실패한 시각에는 가격을 만들어 추가하지 않습니다. 현재 가격은 `history`의 마지막 기록과 일치해야 합니다. 그래프는 이 기록만 연결하므로 첫 기록 하나만 있을 때는 점으로 표시됩니다.

GitHub Actions는 15분 간격으로 실행을 요청합니다. GitHub의 예약 실행은 지연되거나 생략될 수 있으며, 실제 가격을 검증하지 못한 실행은 실패로 표시하면서 기존 가격 이력을 보존합니다. 항공권 사이트의 가격은 예약 단계에서 달라질 수 있습니다.

Skyscanner의 공식 Flights Live Prices API를 사용하려면 제휴 승인 후 저장소 Actions secret `SKYSCANNER_API_KEY`를 설정해야 합니다. 키가 없으면 공개 검색 페이지의 접근 가능 여부만 진단하며, 로봇 확인을 우회하지 않습니다. API 응답에서도 왕복 두 구간의 도시·날짜, 성인 1명, 일반석, KRW 가격을 확인한 경우에만 새 이력을 기록합니다. 현재 이 저장소에는 알림 전송 연동이 없으므로 330,000원 이하 가격도 별도 알림으로 전송되지 않습니다.

Google 항공편은 공개 검색 결과가 정상 표시될 때 화면에서 선택된 왕복·성인 1명·일반석·두 날짜·도시·KRW와 각 결과의 `왕복 총 가격` 표시를 함께 확인합니다. 결과가 로딩 중이거나 오류 화면이면 후보 금액을 새 가격으로 저장하지 않습니다.
